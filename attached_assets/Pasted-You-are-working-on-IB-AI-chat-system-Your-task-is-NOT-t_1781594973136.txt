## IMPLEMENT A 3-LAYER ERROR UX SYSTEM

### STEP 1 — Define UI Error Types

Create:

type UIErrorType =
  | "TRY_AGAIN"
  | "SLOW_DOWN"
  | "BLOCKED"
  | "BAD_INPUT"
  | "TEMP_DOWN"
  | "UNKNOWN";

---

### STEP 2 — Add UX Message Layer

Create a constant:

UI_ERROR_MESSAGES = {
  TRY_AGAIN: "Something went wrong. Please try again.",
  SLOW_DOWN: "You're going a bit fast. Please wait a moment.",
  BLOCKED: "I can’t help with that request.",
  BAD_INPUT: "That message doesn’t look right. Try rephrasing it.",
  TEMP_DOWN: "Service is temporarily unavailable. Please try again shortly.",
  UNKNOWN: "Something went wrong. Please try again."
}

---

### STEP 3 — Add Mapping Function

Create:

function mapBackendErrorToUI(code) {
  switch (code) {
    case "rate_limit":
      return "SLOW_DOWN";

    case "safety_block":
      return "BLOCKED";

    case "invalid_request":
      return "BAD_INPUT";

    case "timeout":
    case "provider_unavailable":
      return "TEMP_DOWN";

    case "internal_error":
      return "TRY_AGAIN";

    default:
      return "UNKNOWN";
  }
}

---

### STEP 4 — Modify useChat.js ONLY

Find ALL places where error messages are displayed such as:

- direct err.message rendering
- fallback error strings

Replace ALL of them with:

const uiType = mapBackendErrorToUI(backendCode);
return UI_ERROR_MESSAGES[uiType];
